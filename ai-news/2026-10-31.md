## 1. [Cursor 插件市场上的「官方」Claude Code 扩展被植入 SSH 后门，约 12 小时、最多 5000 人中招](https://phorion.io/blog/offical-claude-code-vsx-compromise/)
- **要点**：10 月 29 日，Cursor 插件市场上 Anthropic 官方账号下发布了被篡改的 Claude Code for VS Code 2.1.313，会收集主机信息、往 `authorized_keys` 加一把标注为 `svc-telemetry` 的攻击者公钥、开启本机 SSH 并建立反向隧道，macOS、Linux、Windows 都有对应逻辑（[Ars Technica](https://arstechnica.com/security/2026/10/anthropic-vs-code-extension-on-cursor-backdoored-for-nearly-12-hours/)）。Cursor 已下架并发布 2.1.314，Phorion 发现 macOS 上开 SSH 的那一步有 bug，普通用户权限下会跳过，但持久化和回传依然生效。
- **社区观点**：[HN 744 分](https://news.ycombinator.com/item?id=50300683)，Anthropic 的 Felix 在热评里说这不是 Anthropic 系统被攻破，而是有人借 Cursor 市场的权限发布了篡改版；也有人贴出 Reuters 报道的上线时间（太平洋时间周四 2:27 到 13:35）。账号是怎么被控制的，两家都还没解释。
- **为什么重要**：扩展默认自动更新，且以 IDE 的权限运行，能读到源码和本机密钥，这是 AI 编程工具供应链被打穿的标准样本。

## 2. 托管平台接连出事：Northflank 环境变量被解密、AI key 被盗刷，Bunny、Linode、Polymarket 同日公告
- **要点**：[Northflank 状态页](https://status.northflank.com)要求所有用户「假设环境变量已被解密」并立即轮换，多名用户确认自己的 AI API key 被盗用，官方提到 Wiz 的「Black October」报告里有相似 IP。[Bunny CDN](https://status.bunny.net/incidents/p6gf1by9kr7m) 因为亚美尼亚一个节点所在的上游供应商被入侵，正在分批重签所有托管 TLS 证书；[Linode](https://status.linode.com/incidents/nt58zhx3pmgm) 在排查新公开的远程代码执行漏洞 CVE-2026-98432；[Polymarket](https://www.nbcnews.com/business/consumer/polymarket-trading-halt-hack-wallets-rcna606405) 因第三方工具 DebugBear 被攻破停盘近一小时，承诺全额赔付。
- **社区观点**：[HN 上 Northflank 帖](https://news.ycombinator.com/item?id=50305025)的热评数出「从 9 月起至少六起针对多租户服务商的快速攻击」，有人预测企业会因此回流大云厂商；HN 也有人指出 Bunny 的标题有误导，被黑的是上游 Gcore。
- **为什么重要**：攻击者现在专门盯 AI key，因为能直接变现成算力。

## 3. Binance 被盗新进展：约 63 亿美元，大部分在 20 分钟内转走，已冻结一半
- **新进展**：[WIRED](https://www.wired.com/story/the-dollar63-billion-binance-hack-was-pulled-off-in-just-20-minutes/) 引用 TRM Labs 的分析，攻击者至少提前 36 小时准备，先在两个钱包上测试代码、再在第三个钱包演练，四小时后把同一段代码装进 Binance 的热钱包，十多条链上的资金大部分在约 20 分钟内被抽走。Binance 和其他公司已冻结约一半；Elliptic 首席科学家认为朝鲜「很可能」是幕后方，如果属实，这一单就接近朝鲜过往盗取加密资产的总和。
- **社区观点**：[HN](https://news.ycombinator.com/item?id=50303172) 有人说执行快不稀奇，难的是前面多年的准备；也有人怀疑它和第 1 条的扩展投毒时间点重合不是巧合，但这只是猜测，没有证据。

## 4. [OpenAI、Google、微软、Anthropic 同意用 robots.txt 里的同一个「AI 训练退出」标记](https://www.theverge.com/tech/1023763/openai-google-microsoft-ai-scraping-standard-opt-out)
- **要点**：这个共享的 policy token 由 Anthropic 的标准负责人在 IETF 提出，写在 robots.txt 里，四家都说遇到它会限制自己的 AI 爬虫；以前网站得对每家单独设置。微软还会把「不用于训练」和「不用于 AI 引用」分开控制，并说不影响 Bing 搜索排名。Meta 表态支持，但没说会不会遵守（[OpenAI 公告](https://openai.com/index/helping-websites-express-ai-training-preferences)）。
- **为什么重要**：这是第一次主要模型公司对一个统一的退出方式公开承诺，站长终于有了一行就能写清楚的声明。

## 5. Claude 这周的一串变化：Max 更名、顶档取消 5 小时限制，API 请求上限提到 128MB
- **要点**：据 X 新闻汇总，Max 5x 改名 Max（100 美元/月），Max 20x 改名 Ultra（200 美元/月），通过验证的 Ultra 账号取消 5 小时会话上限，周额度不变（[X 新闻](https://x.com/i/trending/2116229906925568174)，[r/ClaudeAI 讨论](https://www.reddit.com/r/ClaudeAI/comments/1xjlvlc/anthropic_renames_max5_and_max20_and_removes_5h/)）。Claude API 的 Messages 请求上限从 32MB 提到 128MB，多图请求的单图分辨率提到 3000 像素（[X 新闻](https://x.com/i/trending/2115959276174979233)）。OpenCode 2.2.3 支持通过本机 Claude Code CLI 登录用订阅额度（[X 新闻](https://x.com/i/trending/2116155705476444635)）。
- **说明**：这几条来自 X 新闻的汇总摘要，我没找到 Anthropic 官方页面逐条核对。
- **为什么重要**：重度用户最烦的是写到一半被 5 小时上限打断，这次直接取消；128MB 让长时间电脑操作和大 PDF 的 agent 更少中途失败。

## 8. [有人把 NES 游戏机塞进了约 1GB 的 Qwen 权重里，能跑超级马里奥（很慢）](https://github.com/dbreunig/nesformer)
- **要点**：Drew Breunig 受 qwenputer 启发，把 NES 的 6502 CPU 模拟器「烘焙」进 Qwen3.5-4B 的权重里，只用了两条给 Opus 5.5 的提示词，Opus 还自己找到了 15 年前的 CPU 一致性测试集（[Simon Willison](https://simonwillison.net/2026/Oct/30/nesformer/)）。
- **社区观点**：[HN](https://news.ycombinator.com/item?id=50306442) 有人兴奋于「在权重里编译一个小虚拟机」的可能性，也有人指出它比真机慢 150 到 290 倍，正好说明 LLM 和普通程序之间的算力差距。

## 9. [Apple Intelligence 终于要进中国：iOS 27.3 接入通义千问](https://www.theverge.com/tech/1023974/apple-intelligence-china-ios-27-3)
